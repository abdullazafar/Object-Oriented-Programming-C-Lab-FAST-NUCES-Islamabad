# Lab 06

This lab focuses on working with **structures, pointers, references, and const references in C++**.

## Topics Covered

* Structures
* Passing structures by pointer
* Passing structures by reference
* Passing structures by const reference
* Modifying original objects through functions
* Preventing unwanted modifications using `const`
* Basic state modification and validation

## Tasks

The lab contains five tasks:

* **Q1:** Account Management
* **Q2:** Vehicle Mileage
* **Q3:** Sensor Reading
* **Q4:** Order Discount Application
* **Q5:** Game Character Stats

Each question is implemented separately in its own `.h` file.
